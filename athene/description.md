# Athene

Athene, like Apollon, is a computer program of the company Seestone. 

It is an audioreactive visual system that reacts to a recorded speech clip. My inspiration currently is the Palantir ball in Lord of the Rings and the ElevenLabs circles found on their website. The audio reactive sphere should be visually coherent with Apollon. It needn't run live - we will render the clips of Athene talking.
